# Наладчик — кабинет инженера

Офлайн-приложение для учёта доходов, ежедневных расходов, долгов и командировок инженера-наладчика. Работает как обычная веб-страница, устанавливается как PWA и синхронизирует данные с приватным GitHub Gist.

**Приложение:** https://fzonov-png.github.io/naladchik/

## Возможности

- **Доходы**: аванс, окончательная зарплата, отпускные, премия, компенсация, прочие поступления.
- **Наличные и безналичные** поступления с указанием источника дохода и объекта.
- **Ежедневные расходы**: продукты, жильё и ЖКХ, транспорт, здоровье, связь, семья, кафе, развлечения, покупки, образование и прочее. Учитываются отдельно от командировочных затрат.
- **Долги**: кредиты, рассрочки, ипотека, займы и кредитные карты. Сумма, платёж в месяц, ставка, день платежа, история платежей, остаток и прогресс погашения.
- **Анализ и рекомендации**: свободный остаток, норма сбережений, долговая нагрузка, правило 50/30/20, крупнейшие категории расходов и персональные советы по бюджету.
- **Командировки**: направление, объект, даты начала и окончания, транспорт, цель поездки.
- **Количество суток рассчитывается автоматически** включительно по датам начала и окончания.
- **Суточные не входят в сумму доходов.** Это возмещение расходов: они показываются отдельно и справочно, но не увеличивают доход ни на одном экране и не попадают в CSV доходов.
- **Расходы в командировке**: проезд, проживание, транспорт на месте, связь, представительские и прочие затраты с датой, документом и способом оплаты. Для каждой поездки указывается аванс, баланс считается автоматически.
- **Авансовый отчёт** по каждой командировке: печатная форма A4 с шапкой организации, таблицей расходов, суточными, итогами, расчётом с подотчётным лицом и подписями.
- **Объекты**: площадки и заказчики с доходами, сутками и суточными по каждому объекту.
- **Отчёты**: доходы и командировки по месяцам, структура по типам, источникам, объектам и направлениям, ежедневные расходы по категориям, долги и платежи, список авансовых отчётов.
- **Фильтры, сортировка, поиск**, периоды «месяц / квартал / год / всё время».
- **Экспорт и импорт**: JSON-резервная копия, CSV доходов, командировок, расходов командировок, ежедневных расходов и долгов.
- **Тёмная и светлая темы**, адаптивная вёрстка, печать отчётов.
- **Офлайн-режим** через service worker.
- **Синхронизация с GitHub** через приватный Gist и Personal Access Token.

## Как хранятся данные

| Где | Что хранится |
| --- | --- |
| `localStorage` браузера | Рабочие данные, настройки, резервная копия |
| Приватный GitHub Gist | Копия данных для синхронизации между устройствами |
| Только в браузере | Personal Access Token |

Токен **не сохраняется** в Gist, не попадает в резервную копию и не должен попадать в репозиторий. Данные в Gist лежат в файле `naladchik-data.json`.

Ключи `localStorage`:

- `naladchik:data:v1` — данные приложения;
- `naladchik:backup:v1` — резервная копия перед импортом или загрузкой из Gist;
- `naladchik:github:v1` — токен, ID Gist и время синхронизации;
- `naladchik:ui:v1` — выбранный период и настройки интерфейса.

## Ежедневные расходы и долги

1. Откройте **Расходы** и нажмите **Расход**: укажите дату, сумму, категорию, способ оплаты и комментарий. Это личные траты, не связанные с командировками.
2. Откройте **Долги** и нажмите **Долг**: заполните название, кредитора, тип, сумму, платёж в месяц, ставку, срок и день платежа.
3. В карточке долга нажмите **Платежи**, чтобы внести фактический платёж. Остаток и прогресс пересчитаются автоматически.
4. Раздел **Анализ** показывает свободный остаток, норму сбережений, долговую нагрузку и рекомендации. Расходы командировок и суточные в личный бюджет не включаются, так как возмещаются работодателем.

## Авансовый отчёт

1. Откройте **Командировки** и нажмите у нужной поездки кнопку расходов (иконка кошелька) или **Расходы и аванс**.
2. Укажите аванс, выданный под отчёт, и добавьте расходы: дату, сумму, вид, документ и способ оплаты.
3. Нажмите **Авансовый отчёт** — откроется печатная форма A4.
4. Кнопка **Печать отчёта** (или Ctrl/Cmd + P) выводит документ на печать или сохраняет в PDF.

В отчёт автоматически попадают расходы, суточные за все сутки поездки, итог, аванс, баланс и подписи. Номер отчёта формируется как `АО-<год>-<код поездки>`. Организация и должность берутся из **Настроек**. Список всех авансовых отчётов доступен в разделе **Отчёты**.

## Подключение GitHub

1. Создайте **classic** Personal Access Token с правом `gist` (или fine-grained token с доступом к Gists).
2. Откройте **Настройки → GitHub**.
3. Вставьте токен. ID Gist можно оставить пустым.
4. Нажмите **Создать Gist** — будет создан приватный Gist с файлом `naladchik-data.json`.
5. Для второго устройства вставьте тот же токен и ID Gist (или ссылку на Gist), затем нажмите **Загрузить**.

Доступны ручные действия «Отправить» и «Загрузить», а также автоматическая синхронизация при изменениях. При конфликте приложение предложит выбрать локальную или удалённую версию.

## Локальный запуск

Из папки проекта:

```powershell
python -m http.server 5173
```

Откройте `http://localhost:5173`.

Приложение не требует сборки: это статические HTML, CSS и JavaScript.

## Публикация на GitHub Pages

Сайт публикуется прямо из ветки `main`, без сборки:

1. Откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку `main` и папку `/ (root)`, сохраните.
4. Сайт будет доступен по адресу `https://fzonov-png.github.io/naladchik/`.

Файл `.nojekyll` отключает обработку Jekyll и сохраняет служебные файлы.

## Приватность и безопасность

- Используйте отдельный токен только с правом `gist`.
- Не публикуйте токен и не добавляйте его в код или резервные копии.
- Gist должен быть **приватным**: приложение создаёт его именно таким.
- Данные хранятся в браузере и в вашем Gist; сторонние серверы не используются.
- Регулярно скачивайте JSON-резервную копию.
